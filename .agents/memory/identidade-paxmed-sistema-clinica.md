description: Regra definitiva (14/11/2026) que substitui a cadeia PAXTER>PARXIS>PADAXOR>PAXMED

PaxMed = nome do SISTEMA licenciado. Instituto Pádua = uma CLÍNICA que usa uma licença; outras clínicas usam o próprio nome. "Paxter" (e Padaxor/Parxis) foi descontinuado como marca.
**Why:** o CEO corrigiu em definitivo; a assistente chamava a clínica pelo nome do sistema.
**How to apply:** texto visível usa PaxMed (sistema); o paciente lê o nome da clínica (empresas.nome) como remetente/assistente, nunca PaxMed e sem nome inventado. Não renomear identificadores técnicos (pastas, componentes Paxter*, skills, chaves localStorage, colunas, variáveis PADAXOR_*, UID .ics). Dados já gravados no banco (modelos, textos antigos) não são reescritos sem ordem. Arte do wordmark "PAXTER" (sidebar/PaxterLockup) ainda é a antiga: trocar pela arte PaxMed em etapa própria.
