Siglas explicadas (sempre, a pedido do CEO):
IHE = Integrative Health Engine (este repositorio, o "Pawards").
ZapSign = provedor de assinatura digital em nuvem (com validade juridica no Brasil).
ICP-Brasil = Infraestrutura de Chaves Publicas Brasileira (assinatura digital de maximo valor legal).
A1 = tipo de certificado digital em arquivo (.pfx), instalado no servidor.
PAdES = PDF Advanced Electronic Signatures (assinatura embutida dentro do proprio PDF).
RAS = Registro de Administracao de Substancias (o documento de execucao clinica).
TCLE = Termo de Consentimento Livre e Esclarecido (paciente concorda com o procedimento).
RACJ = Relatorio de Assistencia com Consentimento Juridico (PDF com termos legais).
API = Application Programming Interface (porta de comunicacao entre sistemas).
Rota = endereco de API (metodo + caminho, ex.: POST /api/assinaturas/enviar).
Webhook = chamada que o ZapSign faz DE VOLTA pro nosso sistema avisando "foi assinado".
DB = Data Base (banco de dados).
Adapter = camada que troca o provedor sem mexer no resto do codigo.
UX = User Experience (experiencia de uso, atrito pro usuario).
PII = Personally Identifiable Information (dado pessoal identificavel).
Env / Secret = variavel de ambiente / segredo (token guardado fora do codigo).

## 5. ARSENAL ZAPSIGN — ROTAS (metodo + caminho)

| Rota | Funcao |
|------|--------|
| `POST /api/assinaturas/enviar` | Cria o documento: hidrata HTML -> gera PDF -> envia ao ZapSign -> grava em assinatura_solicitacoes |
| `POST /api/webhooks/assinatura/zapsign` | Recebe o aviso do ZapSign (valida header x-pawards-secret) -> atualiza status -> dispara efeitos (Drive, aviso CEO) |
| `GET /api/assinaturas/:id/status` | Consulta o status atual da solicitacao |
| `POST /api/assinaturas/:id/signatario/:signatarioId/reenviar` | Reenvia o link pro signatario (chama ZapSign resend) |

5.1 Fluxo ponta a ponta (blueprint com setas):

`criar solicitacao -> hidratar HTML do termo -> htmlParaPdf (PDF base64) -> ZapSign POST /api/v1/docs -> paciente assina (WhatsApp + tela) -> ZapSign dispara webhook doc_signed -> service grava status + pdf_assinado_url -> arquiva PDF no Google Drive do paciente -> avisa o CEO`
