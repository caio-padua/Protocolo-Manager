# INSTRUÇÃO TÉCNICA PARA REPLIT — VETORIZAÇÃO DA LOGO PAXTER

## Objetivo

Não quero que a logo PAXTER seja recriada usando uma fonte parecida.

Quero que a logo seja tratada como uma **marca vetorial customizada**, baseada diretamente na imagem de referência enviada.

A palavra **PAXTER** não deve ser digitada com fonte comum.
Ela deve ser convertida em **SVG paths**, como um desenho fixo, igual a um molde/carbono da imagem.

A ideia é:

```text
imagem PNG de referência → tracing/vetorização → SVG com paths → componente React/TypeScript reutilizável
```

---

# 1. O QUE NÃO FAZER

Não fazer isto:

```tsx
<h1>PAXTER</h1>
```

Não fazer isto:

```tsx
<div style={{ fontFamily: "Cinzel" }}>PAXTER</div>
```

Não usar uma fonte tentando imitar o desenho.

Não usar texto editável para a palavra PAXTER na versão final da logo.

Não tentar “aproximar” com CSS apenas.

A palavra **PAXTER** precisa ser um vetor desenhado, com paths SVG.

---

# 2. O QUE FAZER

Criar a logo como um componente vetorial em React/TypeScript.

Estrutura desejada:

```text
src/
  components/
    branding/
      PaxterLogo.tsx
      paxter-logo.css

  assets/
    brand/
      paxter-reference.png
      paxter-logo.svg
      paxter-wordmark.svg
      paxter-symbol.svg
```

A logo deve ter 3 elementos vetoriais:

1. Símbolo / monograma superior
2. Palavra PAXTER
3. Frases auxiliares em ouro 3D sobressalente

---

# 3. PROCESSO CORRETO

## Etapa 1 — usar a imagem como matriz

Usar a imagem de referência da logo PAXTER como base visual.

A imagem deve ser usada apenas para extrair o formato.

Não usar a imagem PNG final no sistema como logo principal.

O PNG pode ser usado temporariamente apenas como guia.

---

## Etapa 2 — vetorizar a imagem

A palavra PAXTER e o símbolo precisam virar SVG.

Usar um processo de tracing/vetorização.

Opções possíveis:

### Opção A — Inkscape

Abrir a imagem no Inkscape e usar:

```text
Path → Trace Bitmap
```

Depois limpar os paths, remover excesso de pontos, separar camadas e exportar SVG.

### Opção B — Illustrator

Usar:

```text
Image Trace → Expand → Export SVG
```

### Opção C — biblioteca no projeto

Pode usar bibliotecas como:

```bash
npm install imagetracerjs
```

ou ferramenta externa como potrace.

Mas a versão final precisa ser revisada, porque tracing automático pode criar excesso de pontos.

---

# 4. REGRA PRINCIPAL

O resultado final precisa conter paths SVG parecidos com isto:

```tsx
<svg viewBox="0 0 1200 900">
  <path d="M..." />
  <path d="M..." />
  <path d="M..." />
</svg>
```

A palavra PAXTER não deve depender de fonte.

Cada letra deve ser path.

Exemplo conceitual:

```tsx
<g id="paxter-wordmark">
  <path id="letter-p" d="..." />
  <path id="letter-a" d="..." />
  <path id="letter-x" d="..." />
  <path id="letter-t" d="..." />
  <path id="letter-e" d="..." />
  <path id="letter-r" d="..." />
</g>
```

# 6. SÍMBOLO / MONOGRAMA

O símbolo superior deve ser vetorial, não imagem.

Ele deve ser composto por paths grossos, com:

```text
formato geral: monograma premium
aparência: ouro polido
estrutura: moldura arredondada parcial + traço interno + X diagonal
estilo: médico-tecnológico-luxo
```

Características:

```text
largura aproximada: 620 px
altura aproximada: 520 px
espessura principal: 52 px
bevel visual: 8 px
extrusão visual: 18 px
cantos: arredondados
acabamento: polido, limpo, premium
```

O símbolo deve parecer uma peça metálica em ouro, não um ícone plano.

---

# 7. PALAVRA PAXTER

A palavra exata é:

```text
PAXTER
```

A palavra deve ser criada como vetor.

Não usar fonte.

Cada letra precisa ser path SVG.

A palavra deve ter:

```text
altura aproximada: 250 px
largura aproximada: 1340 px
espessura: 6% a 9% mais grossa que a versão anterior
estilo: geométrico, luxo, premium, futurista discreto
material: ouro polido
relevo: mais intenso
```

## Letra P

A letra P é a mais importante.

Ela precisa seguir o P da referência PACTOR/PAXTER anterior.

Descrição obrigatória:

```text
A letra P não deve ser uma letra P comum.
Ela precisa ser vazada.
O interior do P deve ser aberto, mostrando o fundo escuro.
A haste esquerda deve ser reta e robusta.
A barra superior deve ser horizontal e longa.
A curva superior direita deve ser elegante.
A parte interna oposta à curvatura precisa parecer recortada/vazia.
O P precisa parecer uma peça metálica customizada, não uma fonte.
```

Representação conceitual:

```text
P = haste vertical + barra superior + curva parcial + vazio interno real
```

A letra P deve ser convertida em path:

```tsx
<path id="letter-p" d="..." />
```

Não aceitar:

```tsx
<span>P</span>
```

# 13. COMO EXTRAIR O VETOR DA IMAGEM

A tarefa principal é transformar a imagem em vetor.

Processo recomendado:

```text
1. Carregar a imagem de referência.
2. Separar visualmente a palavra PAXTER do fundo.
3. Aumentar contraste.
4. Criar máscara da área dourada.
5. Fazer tracing da máscara.
6. Converter contorno em SVG path.
7. Simplificar pontos sem deformar.
8. Separar cada parte:
   - símbolo
   - letra P
   - letra A
   - letra X
   - letra T
   - letra E
   - letra R
9. Aplicar gradiente de ouro.
10. Aplicar camadas de profundidade.
11. Exportar como componente React.
```

---

# 14. IMPORTANTE SOBRE QUALIDADE

Tracing automático pode gerar SVG sujo.

Depois da vetorização, limpar:

```text
- excesso de pontos
- curvas tremidas
- bordas serrilhadas
- espaços internos irregulares
- desalinhamento entre letras
- espessura inconsistente
```

A versão final precisa parecer desenhada por designer, não extraída de forma automática e suja.
