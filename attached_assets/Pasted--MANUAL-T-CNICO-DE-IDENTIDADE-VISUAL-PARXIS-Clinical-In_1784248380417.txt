# MANUAL TÉCNICO DE IDENTIDADE VISUAL

## PARXIS — Clinical Intelligence System

---

# 1. DIRETRIZ PRINCIPAL

A identidade PARXIS deve transmitir:

* medicina premium;
* inteligência clínica;
* precisão;
* tecnologia;
* exclusividade;
* autoridade;
* luxo clássico;
* sofisticação sem aparência de cassino ou jogo;
* profundidade visual semelhante a metal real usinado.

O logotipo deve manter exatamente o símbolo monograma atual, alterando apenas o nome anteriormente utilizado para:

**PARXIS**

A palavra PARXIS deve possuir o mesmo estilo visual, proporção, acabamento metálico, bevel e profundidade utilizados anteriormente na palavra PAXTER.

---

# 2. ESTRUTURA OFICIAL DA MARCA

A composição principal deverá possuir quatro níveis:

1. Símbolo monograma;
2. Nome PARXIS;
3. Descritor “Clinical Intelligence System”;
4. Assinatura institucional.

Texto da assinatura:

**PRECISION IN INTEGRATIVE CARE**

# 5. SÍMBOLO PRINCIPAL

## 5.1 Proporção

Utilizar o símbolo atual sem modificar seu desenho.

Proporção externa aproximada:

```text
Largura: 1,00
Altura: 1,05
```

Ou seja, a altura pode ser aproximadamente 5% maior que a largura.

Exemplo:

```text
Largura: 600 px
Altura: 630 px
```

## 5.2 Área de proteção

Manter uma margem livre ao redor do símbolo equivalente a:

```text
20% da largura total do símbolo
```

Exemplo:

```text
Símbolo com 600 px de largura
Área livre mínima em cada lado: 120 px
```

Nenhum texto, linha, borda ou elemento decorativo pode entrar nessa área.

## 5.3 Espessura estrutural

A espessura visual média das hastes deve corresponder a:

```text
9% a 12% da largura total do símbolo
```

Exemplo:

```text
Símbolo de 600 px
Espessura média das hastes: 54 a 72 px
```

## 5.4 Bevel do símbolo

Utilizar bevel externo realista.

Configuração recomendada:

```text
Profundidade aparente: 8% a 11% da espessura da haste
Ângulo da luz: 120° a 135°
Altitude da luz: 35° a 45°
Brilho superior: intenso
Sombra inferior: profunda
Contorno interno: fino
Contorno externo: médio
```

Não utilizar bevel exageradamente arredondado.

O acabamento deverá lembrar:

* metal usinado;
* joalheria;
* relógio suíço;
* placa metálica de automóvel premium.

# 7. REFLEXOS DO OURO

Utilizar três tipos de reflexo.

## 7.1 Reflexo longitudinal

Criar uma faixa clara acompanhando as hastes metálicas.

Opacidade:

```text
25% a 45%
```

Largura:

```text
8% a 14% da espessura da haste
```

## 7.2 Reflexo pontual

Adicionar no máximo dois pequenos pontos de luz.

Posições recomendadas:

* canto superior esquerdo;
* parte superior central;
* curva superior direita.

Não espalhar brilhos por todo o logotipo.

## 7.3 Reflexo suave externo

```css
filter:
  drop-shadow(0 5px 8px rgba(0,0,0,0.75))
  drop-shadow(0 0 12px rgba(242,184,23,0.20));
```

O brilho externo dourado deverá ser discreto.

# 8. PALAVRA PARXIS

## 8.1 Grafia obrigatória

```text
PARXIS
```

Todas as letras em caixa alta.

## 8.2 Proporção

A largura da palavra PARXIS deverá corresponder a:

```text
145% a 165% da largura do símbolo
```

Exemplo:

```text
Símbolo: 600 px
PARXIS: 870 a 990 px de largura
```

## 8.3 Altura da palavra

A altura da palavra deverá corresponder a:

```text
22% a 28% da altura do símbolo
```

Exemplo:

```text
Símbolo com 630 px de altura
Altura da palavra: 139 a 176 px
```

## 8.4 Espaçamento entre letras

Utilizar espaçamento relativamente aberto.

```css
letter-spacing: 0.06em a 0.12em;
```

Não deixar as letras excessivamente separadas.

## 8.5 Peso das letras

Usar peso visual:

```text
Medium a SemiBold
```

Não usar Black ou ExtraBold.

A palavra deve parecer robusta, mas elegante.

O “X” deverá ser o ponto de maior identidade da palavra.

# 25. MICROINTERAÇÕES

## Hover

No hover, aumentar discretamente o brilho.

```css

  brightness(1.06)
  drop-shadow(0 0 10px rgba(242,184,23,0.24));
```

Escala:

```css
transform: scale(1.015);
```

Transição:

```css
transition:
  transform 220ms ease,
  filter 220ms ease;
```

## Clique

```css
transform: scale(0.985);
```

Não usar movimentos rápidos ou exagerados.

# 26. ANIMAÇÃO DO SÍMBOLO

Para splash screen ou tela inicial:

1. Símbolo surge com opacidade de 0 para 1;
2. Realiza pequeno movimento vertical;
3. Reflexo atravessa lentamente a superfície;
4. Para completamente;
5. Pode realizar uma respiração muito discreta.

Configuração:

```css
animation-duration: 2.8s;
animation-timing-function: cubic-bezier(.22,.61,.36,1);
```

Respiração:

```text
Escala: 1.000 → 1.012 → 1.000
Duração: 5 a 7 segundos
```

Não utilizar rotação contínua.
