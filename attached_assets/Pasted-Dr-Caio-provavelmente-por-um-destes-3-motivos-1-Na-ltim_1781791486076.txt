### 2. No Replit, o componente não aparece sozinho

O arquivo `VolumeDiscountBlock.tsx` só aparece na tela se ele for **importado e chamado** dentro da página atual do orçamento.

Exemplo:

```tsx
import VolumeDiscountBlock from "./VolumeDiscountBlock";

export default function OrcamentoNovo() {
  return (
    <div>
      <VolumeDiscountBlock />
    </div>
  );
}
```

Se o Replit criou o arquivo, mas não colocou `<VolumeDiscountBlock />` dentro da página `/orcamentos/novo`, nada aparece visualmente.

### 3. O CSS pode não ter sido importado

Dentro do arquivo `VolumeDiscountBlock.tsx`, precisa existir esta linha:

```tsx
import "./VolumeDiscountBlock.css";
```

Sem isso, o bloco pode até aparecer, mas sem forma, sem sombra, sem 3D, ou quase invisível.

O porquinho que eu mandei **não depende de imagem externa**. Ele é um **SVG inline**, ou seja, ele está desenhado dentro do próprio código. Então, se o porquinho não aparece, o problema não é falta de arquivo PNG/JPEG. O problema normalmente é:

```txt
1. o componente não foi chamado na tela;
2. o CSS não foi importado;
3. o Replit colocou o código em outra pasta;
4. existe erro de TypeScript impedindo a compilação;
5. a página certa não está usando o componente.
```
