Minha resposta honesta às três perguntas
Railway é a melhor opção para o sistema? Sim. API Node + Postgres + rede privada entre eles é exatamente o que ele faz bem. Não mudaria.

Railway é a melhor opção para o site do Lovable? Não. Vercel ou Cloudflare seriam mais naturais, grátis, e sem eu forçar variável nenhuma.

Seu site vai conseguir usar o Lovable? Sim — mas atenção: o Lovable publica sozinho, com URL própria, sem Railway nenhum. O botão Publish que aparece na tela dele já faz isso. Você talvez não precise de mim para isso.

Sobre "concentrar"
Aqui eu discordo um pouco de você, e vou dizer o porquê.

Concentrar tem valor real: uma conta, uma fatura, um lugar para olhar. Mas o site e o sistema são coisas diferentes. Site é página que carrega rápido e muda toda semana. Sistema é processo que fica ligado, guarda prontuário, conversa com banco. Juntar os dois no mesmo lugar não simplifica — só obriga um dos dois a viver num lugar que não é o dele.

O que de fato simplifica é um domínio só: padaxor.com.br no site, api.padaxor.com.br no sistema. Para você e para o cliente, é um endereço. Onde cada um roda vira detalhe invisível.
