O símbolo da PADCON não ficava simplesmente “parado” no centro. Ele era tratado como uma peça metálica tridimensional independente do restante do layout, com três efeitos combinados:

uma inclinação leve em perspectiva, para não parecer uma imagem plana;
uma flutuação vertical lenta, subindo e descendo poucos pixels;
uma respiração visual, expandindo e reduzindo muito discretamente;
além de uma sombra dinâmica que acompanhava o movimento.

A lógica visual era aproximadamente esta:

transform:
  perspective(1000px)
  rotateX(4deg)
  rotateY(-7deg)
  translateY(-4px)
  scale(1.01);

E a animação de respiração:

@keyframes padconBreathing {
  0% {
    transform:
      perspective(1000px)
      rotateX(4deg)
      rotateY(-7deg)
      translateY(0)
      scale(1);
  }

  50% {
    transform:
      perspective(1000px)
      rotateX(3deg)
      rotateY(-6deg)
      translateY(-10px)
      scale(1.025);
  }

  100% {
    transform:
      perspective(1000px)
      rotateX(4deg)
      rotateY(-7deg)
      translateY(0)
      scale(1);
  }
}

Aplicação:

.padcon-floating-symbol {
  animation: padconBreathing 6.5s ease-in-out infinite;
  transform-origin: center center;

  filter:
    drop-shadow(0 22px 24px rgba(0, 0, 0, 0.48))
    drop-shadow(0 0 12px rgba(226, 174, 55, 0.18));

  will-change: transform, filter;
}

O efeito ideal não era de um objeto “pulando”. Era como se o símbolo:

estivesse suspenso no ar, respirasse lentamente, ganhasse presença e depois voltasse ao repouso.

Também havíamos pensado em um reflexo metálico atravessando o símbolo apenas ocasionalmente, e não de forma contínua, para evitar aparência de cassino ou de jogo.

Para o símbolo PARXIS, eu manteria a mesma lógica, mas faria a animação ainda mais refinada:

Duração total: 7,2 segundos
Subida máxima: 8 px
Escala máxima: 1,018
Inclinação horizontal: -5°
Inclinação vertical: 3°
Pausa visual no topo: aproximadamente 500 ms
Glow dourado: opacidade máxima de 18%

A sequência seria:

1. repouso;
2. subida lenta;
3. pequena expansão;
4. pausa;
5. retorno mais lento;
6. reflexo dourado atravessando apenas a cada 12–16 segundos.

O resultado combina muito com a proposta que aparece no seu print: arquitetura clássica, fundo marrom profundo, moldura dourada e o símbolo como uma peça de joalheria flutuante no centro.
