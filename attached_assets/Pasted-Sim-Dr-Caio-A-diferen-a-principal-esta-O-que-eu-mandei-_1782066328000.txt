3. Tradução para o senhor entender

Termo visual	O que significa na prática
Hover	Efeito quando o mouse fica em cima do item
Glow	Luz suave em volta ou atrás
Neon discreto	Luz elegante, não chamativa demais
Beacon	Sinalizador lateral, como uma “faixa de atenção”
Pulse	Brilho que respira/pisca devagar
State / Estado	Situação do item: atrasado, atenção, concluído, normal
Classe CSS	Nome técnico que ativa o visual
Condicional TypeScript	Regra que decide se o card deve brilhar ou não

4. Tradução para o Replit entender

O que o senhor quer	O que o Replit deve implementar
“Luzinha saindo por trás”	box-shadow + ::after com filter: blur()
“Quando passar o mouse”	.card:hover
“Quando paciente atrasar”	.card.is-late
“Quando precisa agendar”	.card.is-attention
“Quando for alerta amarelo”	.card.is-warning
“Quando for grave/vermelho”	.card.is-danger
“Barra lateral iluminada”	.card::before ou border-left com sombra
“Não quero tudo brilhando”	Aplicar classe apenas quando houver status real
“Quero elegante”	Reduzir opacidade, blur e saturação

7. Orientação exata para o Replit

Copie isto para ele:

Não aplicar glow em todos os cards.
Manter o layout atual.
Criar 3 níveis de sinalização:
1. Luxury Glow:
- Usar apenas em hover desktop.
- Classe: .pw-hover-luxury
- Efeito: luz suave saindo de baixo do card.
- Não deve ficar fixo no mobile.
2. Agendamento Prioritário:
- Usar quando paciente precisar de agendamento, retorno ou continuação de protocolo.
- Classe: .is-attention
- Card deve ter borda champagne mais evidente, leve elevação e botão de ação destacado.
3. Side Beacon:
- Usar para alertas operacionais.
- Classe: .has-side-beacon
- Barra lateral de 4px a 5px, com cor conforme status:
  - âmbar: atenção
  - vermelho: atraso/crítico
  - verde: concluído
  - azul: informação
No celular:
- Não depender de :hover.
- Apenas cards com status real devem ter brilho fixo.
No desktop:
- Cards normais podem ter hover discreto.
- Cards com problema devem ter estado fixo + hover.

9. A frase mais importante para o Replit

O efeito não é decoração global. O efeito é uma linguagem de estado.
Cada card só deve brilhar quando o TypeScript disser que ele está em atenção, atraso, perigo, sucesso ou hover.

Essa é a diferença técnica central.
