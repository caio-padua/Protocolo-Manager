A base técnica anterior que já vínhamos usando é o layout React/TypeScript com cards 3D, sombras, bordas, botões e paleta em variáveis CSS. Vou evoluir isso para uma identidade **PAWARDS System / Clinical Intelligence Platform**.

# 1. Direção visual recomendada

Para o PAWARDS, eu usaria:

```txt
Azul-marinho profundo + champagne metálico + branco gelo + cinza pérola.
```

Por quê?

O **azul-marinho** comunica autoridade, medicina executiva, segurança e discrição.

O **champagne/dourado suave** comunica valor, alta renda, concierge, premium e excelência.

O **branco gelo** mantém a tela limpa, médica e objetiva.

O **cinza pérola** mantém elegância sem deixar o sistema pesado.

Eu evitaria:

```txt
Verde muito hospitalar.
Verde neon excessivo.
Azul muito elétrico.
Muito degradê colorido.
Cantos muito arredondados.
Sombras exageradas que pareçam jogo/app infantil.
```

O padrão ideal é: **3D clássico, sóbrio, com relevo tipo Windows XP/Excel premium**, mas em linguagem contemporânea.

# 10. O que o Replit deve trocar no sistema atual

## Trocar nomes

```txt
PADCON -> PAWARDS
Padcon Connect -> Pawards Clinical Intelligence
Motor Clínico -> Executive Medical OS
Protocolos Injetáveis -> Medicina Integrativa Premium
```

## Trocar a cor da sidebar

Remover verde petróleo como cor principal da lateral:

```css
background: #003f42;
```

Substituir por azul-marinho premium:

```css
background:
  radial-gradient(circle at 24% 0%, rgba(207, 163, 94, 0.18), transparent 28%),
  linear-gradient(180deg, #0d294a 0%, #0a1f3a 44%, #061426 100%);
```

## Trocar acento neon verde por champagne

Remover:

```css
box-shadow: 0 0 18px rgba(30, 255, 240, 0.18);
```

Colocar:

```css
box-shadow:
  0 0 22px rgba(207, 163, 94, 0.22),
  inset 0 2px 0 rgba(255, 255, 255, 0.10),
  inset 0 -3px 7px rgba(0, 0, 0, 0.24);
```

## Reduzir arredondamento exagerado

Onde estiver:

```css
border-radius: 20px;
border-radius: 26px;
border-radius: 32px;
```

Preferir:

```css
border-radius: 8px;
border-radius: 10px;
border-radius: 14px;
```

A exceção pode ser apenas avatar, selo, medalha e ícones circulares.
