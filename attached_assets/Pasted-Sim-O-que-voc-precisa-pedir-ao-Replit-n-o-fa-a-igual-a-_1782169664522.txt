# ESPECIFICAÇÃO TÉCNICA — LOGO PAXTER

## Objetivo

Implementar no sistema uma versão vetorial/renderizada da identidade visual **PAXTER**, com aparência premium, luxo discreto, ouro polido normal, relevo 3D mais intenso e acabamento sofisticado.

A logo deve ser composta por 3 elementos principais:

1. **Símbolo / monograma superior**
2. **Nome PAXTER**
3. **Frases auxiliares renderizadas em 3D**

A estética geral deve seguir o padrão visual de uma marca médica/tecnológica premium: fundo escuro, ouro polido, profundidade, sombra elegante, brilho controlado e acabamento limpo.

---

# 1. SÍMBOLO / MONOGRAMA SUPERIOR

## Descrição visual

O símbolo superior deve parecer um monograma abstrato, geométrico e premium, combinando visualmente as ideias de:

* Letra **P**
* Letra **X**
* Símbolo médico/tecnológico sofisticado
* Forma de emblema em moldura arredondada parcial

O símbolo não deve parecer uma ilustração comum. Ele deve parecer uma peça metálica em ouro, como se fosse uma joia ou emblema de luxo.

## Estrutura geométrica

O símbolo deve ter:

* Formato geral quase quadrado.
* Cantos superiores arredondados.
* Traço externo grosso, como uma moldura incompleta.
* Parte superior com curva arredondada.
* Lado esquerdo vertical com extremidade inferior chanfrada.
* Lado direito com curva descendo e abrindo na lateral.
* Elemento interno curvo lembrando a parte superior de um “P”.
* Um traço diagonal cruzando o centro, formando leitura de “X”.
* Base diagonal inferior formando a segunda perna do “X”.

## Proporção

Usar viewBox SVG sugerido:

```svg
viewBox="0 0 600 500"
```

O símbolo deve ocupar aproximadamente:

* Largura: 360 a 420 unidades dentro do viewBox.
* Altura: 300 a 360 unidades.
* Centro horizontal: 300.
* Topo: entre 40 e 60.
* Base: entre 380 e 420.

## Espessura

A espessura visual dos traços deve ser robusta:

* Traço principal: 42 px a 56 px.
* Cantos arredondados: radius visual de 40 px a 70 px.
* Bevel aparente: 6 px a 10 px.
* Extrusão / relevo: 14 px a 20 px.

## Material

Aplicar ouro polido normal, não envelhecido.

Evitar:

* Ouro queimado demais.
* Bronze.
* Ouro antigo.
* Textura suja.
* Excesso de brilho amarelo estourado.
* Aparência chamativa demais.

Usar padrão de ouro:

```css
--gold-base: #D9A441;
--gold-light: #FFF1A8;
--gold-mid: #F2C45C;
--gold-deep: #8C5A13;
--gold-shadow: #3A2206;
```

Gradiente sugerido:

```css
background: linear-gradient(
  135deg,
  #7a4a0a 0%,
  #d9a441 18%,
  #fff1a8 34%,
  #f2c45c 48%,
  #a66b16 65%,
  #ffd978 82%,
  #6e4208 100%
);
```

## Relevo / sobressalente

O símbolo deve ter relevo mais intenso que a versão anterior.

Aplicar:

```css
filter:
  drop-shadow(0px 3px 0px #5f3708)
  drop-shadow(0px 8px 10px rgba(0,0,0,0.65))
  drop-shadow(0px 18px 26px rgba(0,0,0,0.45));
```

Também aplicar brilho superior discreto:

```css
box-shadow:
  inset 0 2px 3px rgba(255,255,255,0.85),
  inset 0 -4px 6px rgba(70,35,0,0.65),
  0 10px 24px rgba(0,0,0,0.55);
```

## Acabamento

O símbolo deve parecer:

* Ouro polido.
* Superfície lisa.
* Bevel chanfrado.
* Reflexo controlado.
* Luxo discreto.
* Sem brilho exagerado.
* Sem aparência envelhecida.

# 2. NOME “PAXTER”

## Texto exato

O texto principal deve ser:

```text
PAXTER
```

## Estilo geral

O nome deve ser em letras maiúsculas, metálicas, geométricas e premium.

A palavra **PAXTER** deve ficar:

* Centralizada.
* Grande.
* Em ouro polido normal.
* Em 3D.
* Com relevo mais evidente.
* Um pouco mais grossa que a versão anterior.

## Espessura desejada

A versão anterior ficou levemente fina. Aumentar a espessura do nome **PAXTER** em aproximadamente:

```text
+6% a +9%
```

Não aumentar muito. O ajuste deve ser sutil.

Parâmetros sugeridos:

```css
font-weight: 700;
letter-spacing: 0.08em;
transform: scaleX(1.04);
```

Caso seja SVG path manual:

* Aumentar a largura dos traços em 6% a 9%.
* Manter a altura original.
* Não deformar a palavra.
* Não deixar pesada demais.

## Letra P específica

A letra **P** do PAXTER é crítica.

Ela deve seguir o modelo do “P” da referência PACTOR:

* “P” geométrico.
* Parte superior horizontal longa.
* Curva direita arredondada.
* Abertura interna vazada.
* A parte oposta à curvatura deve parecer “vazia”/recortada.
* Não usar um P comum de fonte tradicional.
* Não fechar totalmente o bojo do P.
* O P deve ter aspecto de peça metálica aberta, elegante e futurista.

Descrição técnica do P:

```text
O P deve ser construído como uma haste vertical esquerda + barra superior horizontal + curva superior direita parcial, com recorte interno vazado. A área interna do P deve mostrar o fundo escuro, criando um vazio real. A forma não deve parecer uma letra P tradicional fechada; deve parecer uma letra P premium customizada, vazada e geométrica.
```

## Letras restantes

### A

* Estilo geométrico.
* Sem barra horizontal tradicional ou com barra muito discreta.
* Parecer um triângulo aberto premium.
* Bevel metálico.

### X

* Cruzamento central forte.
* Duas hastes diagonais com chanfrados.
* O ponto de cruzamento pode ter destaque de brilho.

### T

* Barra superior reta e forte.
* Haste central.
* Bevel nas extremidades.

### E

* Três barras horizontais.
* Barra vertical esquerda discreta ou integrada.
* Estilo futurista.
* Espaço interno escuro visível.

### R

* Curva superior elegante.
* Perna diagonal inferior.
* Não parecer fonte comum.
* Manter linguagem geométrica.

# REGRAS IMPORTANTES PARA O REPLIT

## Não fazer

Não usar:

* PNG achatado como logo final.
* Texto comum sem relevo.
* Ouro envelhecido.
* Bronze.
* Dourado laranja.
* Glow exagerado.
* Sombra borrada demais.
* Fonte padrão comum.
* Letra P tradicional fechada.
* Frases auxiliares chapadas/sem 3D.

## Fazer

Usar:

* SVG sempre que possível.
* Texto convertido em path para versão final.
* Gradiente de ouro polido.
* Bevel simulado.
* Camadas de profundidade.
* Sombras controladas.
* Fundo preto/navy texturizado.
* Palavra PAXTER levemente mais grossa.
* Frases auxiliares também em 3D e sobressalentes.
* Relevo maior que a imagem anterior.
