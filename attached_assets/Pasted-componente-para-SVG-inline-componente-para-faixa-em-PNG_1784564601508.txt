Como funciona a “chavinha”

O estado guarda somente o ID:

const [modelId, setModelId] =
  useState<ArabesqueModelId>("classic-svg");

O seletor:

<ArabesqueModelSelector
  value={modelId}
  onChange={setModelId}
/>

Aplicação superior:

<ArabesqueBand modelId={modelId}>
  <article className="info-card">
    Identificação do paciente
  </article>

  <article className="info-card">
    Identificação do emitente
  </article>
</ArabesqueBand>

Aplicação inferior:

<ArabesqueBand modelId={modelId}>
  <article className="info-card">
    Identificação do comprador
  </article>

  <article className="info-card">
    Identificação do fornecedor / farmácia
  </article>
</ArabesqueBand>

Ao trocar a chave, as duas faixas mudam juntas.

Regra para opção de imagem

A faixa raster fornecida possui:

2325 × 300 px
Proporção: 7,75:1
Correspondência física: 186 × 24 mm
Resolução aproximada: 300 dpi

Ela deve ser inserida assim:

<img
  src="/assets/arabesques/band-classic-2325x300.png"
  className="arabesque-band__image"
  alt=""
/>

CSS:

.arabesque-band__image {
  display: block;
  width: 100%;
  height: 100%;
  object-fit: cover;
  object-position: center;
}

Não usar:

background-size: 100% 100%;
Instrução definitiva para o Replit
Não redesenhe o arabesco.

Implemente dois motores:

1. inline-svg:
   o SVG deve existir diretamente no DOM;
   não usar background-image externo;
   usar <pattern> e <rect>;
   destinado ao PDF vetorial.

2. raster-strip:
   usar uma imagem PNG pronta de 2325 × 300 px;
   posicionada como <img> absoluto;
   não repetir, não redesenhar e não deformar.

A faixa deve ser criada uma única vez, de ponta a ponta,
em z-index 0.

Os cartões devem ser colocados depois, em z-index 2,
com fundo branco opaco.

O mesmo arabesqueModelId deve controlar a faixa superior
e a faixa inferior.

Os modelos devem estar cadastrados em arabesqueModels.ts.
Não criar condições ou estilos espalhados pelo componente
do receituário.

A arquitetura mais segura para a PARXIS é: SVG inline para os modelos oficiais e imagem pronta para os modelos visuais fechados. Assim você terá fidelidade, qualidade de impressão e liberdade para cadastrar novos modelos sem alterar a estrutura do receituário.
